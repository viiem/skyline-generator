#Skyline Art Generator
by ememviit
Programmed with Python, using pygame and pillow(pil) for image generation
An application of my previously made Procedural Art Generator

#Randomly generates an image of a cartoon skyline
Automatically creates a folder called 'generated art' to save images in

#Interactive:
Click to generate a new artwork.
Press S to save the artwork.
